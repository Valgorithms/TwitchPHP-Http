HttpInterface
in
  • Application

HttpInterface.php : 25

The contract {@see Http} fulfils. Depend on this rather than the concrete class so the transport can be decorated or faked (auth-refresh wrappers, test doubles, alternative drivers).

Every method resolves with the decoded JSON body — Twitch's { "data": [...], "pagination": {...} } envelope untouched — or null for a 204, and rejects with a HttpException subclass otherwise.
