Endpoint.php : 26

The set of Twitch Helix endpoints, relative to {@see Http::BASE_URL}.

Twitch Helix is almost entirely query-parameter driven — path parameters are rare (only a couple of the extension endpoints use them). Bind those with bind() / bindAssoc(); everything else goes through addQuery() / withQuery().
