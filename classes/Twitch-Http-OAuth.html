FinalYes
OAuth.php : 40

Thin async wrapper around the Twitch OAuth2 endpoints on `id.twitch.tv`.

Supports the flows a bot or service needs:

  • clientCredentials() — an app access token (no user context).
  • authorizeUrl() + exchangeCode() — the authorization-code flow for a user access token.
  • refreshToken() — trade a refresh token for a fresh access token.
  • deviceCode() + pollDeviceToken() — the device-code flow for headless clients.
  • validate() / revoke().
